Slug: button-hover
Title: Button Hover
Description: 체크박스로 마우스 오버 상태를 흉내내어 버튼이 커지는 것을 표현(목업/프로토타입용).
Property: ① Effect → Expression Controls → Checkbox Control 추가
② Scale에 아래 코드 적용

Use Cases:
- 🖥️ UI 목업 영상
- 📱 인터랙션 프로토타입 시연

Expression:
```jsx
hover = effect("Checkbox Control")("Checkbox");
s = hover == 1 ? 110 : 100;
[s, s];
```

Controls:
- 없음(체크박스로 On/Off)

Result:
체크박스를 체크하는 타이밍에 맞춰 버튼이 110%로 커짐(호버 상태 연출).

Cautions:
- 실제 마우스 커서 위치를 추적하는 게 아니라, 체크박스 키프레임으로 "지금 호버 상태다"를 수동으로 지정하는 방식입니다.

Tips:
- 110 대신 105 정도로 낮추면 더 은은한 호버 효과가 됩니다.
