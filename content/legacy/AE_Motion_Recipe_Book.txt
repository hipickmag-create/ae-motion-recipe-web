## CHAPTER 01. Motion Basics

<a id="r01"></a>
### #01. Float — 둥둥 떠다니기

**한 줄 설명**
공중에 살짝 뜬 듯한 느리고 우아한 상하 움직임.

**적용 속성**
Layer → Transform → Position

**Expression**
```
freq = 0.4; amp = 15;
value + [0, Math.sin(time * freq) * amp];
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 뜨는 속도 | 0.2 ~ 0.6 |
| amp | 뜨는 높이(px) | 10 ~ 30 |

**결과**
위아래로 천천히, 부드럽게 떠 있는 느낌.

**활용 예시**
🎈 풍선 · 🧊 아이콘 · 🛍️ 제품컷 소품 · ☁️ 배경 오브젝트

**주의사항**
Position은 `[x, y]` 배열이라 반드시 `value + [0, ...]` 형태로 y값만 더해야 합니다. `value + Math.sin(...)` 처럼 숫자만 더하면 에러가 납니다.

**초보 TIP**
freq를 0.5보다 낮게 쓰면 "정말 떠 있는" 느낌이 나고, 1 이상으로 올리면 오히려 통통 튀는(#04 Bob) 느낌에 가까워집니다.

**함께 쓰면 좋은 레시피**
#03 Swing과 함께 Position+Rotation에 각각 적용하면 제품컷 부유감 연출에 좋습니다. (#71 조합 참고)

<a id="r02"></a>
### #02. Wiggle — 자연스러운 흔들림

**한 줄 설명**
가장 기본적인 무작위 흔들림. 유기적인 움직임이 필요할 때 만능으로 사용.

**적용 속성**
Layer → Transform → Position

**Expression**
```
freq = 2; amp = 20;
wiggle(freq, amp);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 초당 흔들리는 횟수 | 1 ~ 4 |
| amp | 흔들리는 거리(px) | 5 ~ 40 |

**결과**
무작위지만 자연스러운 떨림.

**활용 예시**
🌳 나무 · 🐟 물고기 · 📦 상자 더미 · ✨ 파티클류 오브젝트

**주의사항**
`wiggle()`은 AE 내장 함수라 변수 선언 없이도 작동하지만, 이 문서에서는 튜닝 편의를 위해 freq/amp로 선언 후 사용합니다. Rotation·Scale에도 그대로 적용 가능합니다.

**초보 TIP**
같은 코드를 여러 레이어에 그대로 복붙하면 전부 똑같이 흔들려서 부자연스러워요. 레이어마다 다르게 흔들고 싶다면 #29 Seed Random을 참고하세요.

**함께 쓰면 좋은 레시피**
#29(레이어별 다른 랜덤), #05(Vibration, 더 빠른 버전)

<a id="r03"></a>
### #03. Swing — 바람에 흔들리기(좌우 흔들기)

**한 줄 설명**
나뭇잎, 간판, 전등, 식물처럼 한쪽을 축으로 자연스럽게 흔들리는 움직임.

**적용 속성**
Layer → Transform → Rotation

**Expression**
```
freq = 1; amp = 8;
value + Math.sin(time * freq) * amp;
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 흔들리는 속도 | 0.3 ~ 3 |
| amp | 흔들리는 각도 | 2 ~ 20 |

**결과**
좌우로 부드럽고 반복적인 흔들림.

**활용 예시**
🌿 나뭇잎 · 🌾 풀 · 🏮 간판 · 💡 전등 · 🎈 매달린 소품
- `freq=0.5; amp=5;` ➡️ 잔잔한 바람
- `freq=2; amp=15;` ➡️ 강한 바람

**주의사항**
회전축이 레이어 정중앙(기본 앵커포인트)에 있으면 물체 전체가 제자리에서 도는 것처럼 보여 어색합니다.

**초보 TIP**
앵커 포인트(Anchor Point)를 회전축이 될 위치로 옮기세요. 나뭇잎→줄기 쪽, 간판→윗부분, 전등→천장 연결부처럼 실제 물체의 고정점에 맞추면 훨씬 자연스럽습니다.

**함께 쓰면 좋은 레시피**
#01(Float)과 Position+Rotation으로 조합하면 매달린 소품 연출에 좋습니다.

<a id="r04"></a>
### #04. Bob — 위아래 흔들기

**한 줄 설명**
Swing과 달리 회전이 아니라 통통 튀듯 반복되는 상하 움직임.

**적용 속성**
Layer → Transform → Position

**Expression**
```
freq = 2; amp = 12;
value + [0, Math.abs(Math.sin(time * freq)) * -amp];
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 튀는 속도 | 1 ~ 3 |
| amp | 튀는 높이(px) | 5 ~ 20 |

**결과**
한쪽 방향(위)으로만 통통 튀는 리드미컬한 움직임.

**활용 예시**
🔴 버튼 강조 · 🖱️ 클릭 유도 아이콘 · ⬇️ 스크롤 유도 화살표

**주의사항**
`Math.abs()`로 감싸져 있어 항상 위로만 튑니다. 아래로도 오가게 하려면 `Math.abs()`를 빼고 `Math.sin(time*freq)*amp`만 쓰면 #01 Float과 비슷해집니다.

**초보 TIP**
클릭/스크롤 유도 아이콘에 쓸 땐 amp를 너무 크게 하지 마세요(10px 이하 권장) — 과하면 산만해 보입니다.

**함께 쓰면 좋은 레시피**
#12(Opacity Blink)와 같이 쓰면 "여기 눌러주세요" 느낌의 유도 아이콘이 완성됩니다.

### #05. Vibration — 진동 효과

**한 줄 설명**
아주 빠르고 미세하게 떠는, 긴장감 있는 흔들림.

**적용 속성**
Layer → Transform → Position

**Expression**
```
freq = 20; amp = 3;
wiggle(freq, amp);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 떨림 속도(높을수록 미세하게 빠름) | 15 ~ 30 |
| amp | 떨림 폭(px, 작게 유지) | 1 ~ 5 |

**결과**
긴장·놀람 상태를 표현하는 듯한 미세 떨림.

**활용 예시**
📱 알림 아이콘 · ⚡ 경고 효과 · 🎮 임팩트 강조

**주의사항**
amp를 5px 이상으로 키우면 "떨림"이 아니라 그냥 #02 Wiggle처럼 보입니다. 이 레시피의 핵심은 freq는 높고 amp는 작다는 대비입니다.

**초보 TIP**
경고/알림 용도로 쓸 땐 #12(Opacity Blink)와 함께 써서 빨간색으로 깜빡이며 떠는 조합이 효과적입니다.

**함께 쓰면 좋은 레시피**
#12 Opacity Blink, #28 Random Opacity

<a id="r06"></a>
### #06. Decay Shake — 흔들리다 멈추기

**한 줄 설명**
충격을 받은 것처럼 강하게 흔들리다가 서서히 멈추는 움직임.

**적용 속성**
Layer → Transform → Rotation (Position에도 동일 구조 적용 가능)

**Expression**
```
freq = 10; decay = 4; amp = 15;
t = time - inPoint;
amp * Math.sin(freq * t) * Math.exp(-decay * t);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 떠는 속도 | 6 ~ 15 |
| decay | 멈추는 속도(클수록 빨리 멈춤) | 2 ~ 8 |
| amp | 처음 떨리는 폭 | 10 ~ 25 |

**결과**
`inPoint`(레이어 시작 시점) 기준으로 한 번 강하게 떨리다 잦아듦.

**활용 예시**
💥 충돌 연출 · 📦 물건이 착지하는 순간 · 🔔 벨/알림이 울린 직후

**주의사항**
`inPoint`는 "레이어가 시작되는 시점"이라 충격이 발생하는 정확한 타이밍에 레이어를 분할(Split Layer)해서 그 지점부터 시작하게 만들어야 원하는 순간에 흔들립니다.

**초보 TIP**
특정 시점(예: 3초)에 충격을 주고 싶다면 `t = time - inPoint` 대신 `t = time - 3`으로 바꾸고 조건문 `t > 0 ? ... : 0`을 앞에 붙이면 더 정확합니다.

**함께 쓰면 좋은 레시피**
#18 Damped Oscillation(같은 원리의 회전 전용 버전), #55 Camera Shake와 결합해 임팩트 컷 연출

### #11. Scale Pulse — Scale 펄스

**한 줄 설명**
일정한 리듬으로 커졌다 작아지는 걸 무한 반복.

**적용 속성**
Layer → Transform → Scale

**Expression**
```
freq = 2; amp = 8;
s = 100 + Math.sin(time * freq) * amp;
[s, s];
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 펄스 속도 | 1 ~ 3 |
| amp | 커지는 정도(%) | 3 ~ 15 |

**결과**
100% 기준으로 커졌다 작아지는 것을 반복.

**활용 예시**
💓 좋아요/하트 애니메이션 · 🔴 라이브 표시 · 📍 지도 핀 강조

**주의사항**
Scale은 `[가로, 세로]` 배열이라 `[s, s]`처럼 두 값을 모두 넣어줘야 합니다. `s`만 반환하면 에러가 납니다.

**초보 TIP**
가로세로를 다르게 펄스시키고 싶으면 `[s, s*0.8]` 처럼 세로만 다른 배율을 곱해보세요.

### #12. Opacity Blink — Opacity 반복

**한 줄 설명**
투명도가 규칙적으로 깜빡이는 것을 반복.

**적용 속성**

**Expression**
```

```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 깜빡이는 속도 | 1 ~ 4 |

**결과**
0~100%를 오가며 규칙적으로 깜빡임.

**초보 TIP**
완전히 꺼지지 않고 은은하게 깜빡이게 하려면 `Math.abs(Math.sin(time*freq)) * 60 + 40` 처럼 최소값을 더해주세요.

## CHAPTER 03. Bounce & Spring

<a id="r13"></a>
### #13. Bounce — 바운스

**한 줄 설명**
키프레임으로 이동을 준 뒤, 도착 지점에서 공처럼 통통 튀며 멈춤.

**적용 속성**
Position 등 키프레임이 있는 속성 (최소 2개 키프레임 필요)

**Expression**
```
freq = 3; decay = 4;
n = 0;
if (numKeys > 0) {
  n = nearestKey(time).index;
  if (key(n).time > time) n--;
}
if (n > 0) {
  t = time - key(n).time;
  v = velocityAtTime(key(n).time - 0.01);
  amp = 0.05;
  if (t < 3 / freq) {
    value + v * amp * Math.sin(freq * t * 2 * Math.PI) * Math.exp(-decay * t);
  } else {
    value;
  }
} else {
  value;
}
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 튕기는 속도 | 2 ~ 5 |
| decay | 멈추는 속도 | 3 ~ 8 |
| amp(코드 내부) | 튕기는 폭 | 0.02 ~ 0.1 |

**결과**
마지막 키프레임에 도착한 뒤 관성으로 몇 번 튕기다 멈춤.

**활용 예시**
🏀 등장/퇴장 모션 · 🔘 버튼 팝업 · 📦 아이콘 드롭

**주의사항**
반드시 이동 애니메이션에 키프레임이 2개 이상 있어야 하고, 마지막 키프레임 이후 구간에 이 익스프레션이 적용돼야 튕기는 게 보입니다. 키프레임이 없으면 항상 `value`만 반환합니다.

**초보 TIP**
너무 복잡해 보이면 코드 자체는 건드리지 말고 freq, decay, amp 세 숫자만 바꿔가며 감을 잡으세요. 나머지 구조는 그대로 둬도 됩니다.

**함께 쓰면 좋은 레시피**
#17 Inertia(같은 원리의 범용 버전, Scale·Rotation에도 적용 가능)

### #14. Elastic Pop-in — 탄성 스케일

**한 줄 설명**
0에서 목표 크기까지 통통 튀며 등장.

**적용 속성**
Layer → Transform → Scale

**Expression**
```
freq = 5; decay = 6; target = 100;
t = time - inPoint;
s = target + target * Math.exp(-decay * t) * Math.cos(freq * t) * (t > 0 ? 1 : 0);
[s, s];
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 튕기는 진동수 | 3 ~ 8 |
| decay | 진정되는 속도 | 4 ~ 10 |
| target | 최종 크기(%) | 100 |

**결과**
레이어 시작 지점(inPoint)부터 튕기며 커져서 정착.

**활용 예시**
🎉 로고/뱃지 등장 · 🔘 버튼 팝업 · 📢 강조 텍스트 등장

**주의사항**
시작 시점이 `inPoint`이므로, 원하는 타이밍에 등장시키려면 레이어 시작점을 그 타이밍에 맞춰 옮겨야 합니다.

**초보 TIP**
decay를 낮추면(3~4) 더 오래 튕기고, 높이면(8~10) 한두 번만 튕기고 바로 멈춥니다.

### #15. Squash & Stretch — 젤리 효과

**한 줄 설명**
이동하는 방향에 따라 눌리고 늘어나는 말랑한 느낌.

**적용 속성**

### #16. Overshoot — 오버슈트

**한 줄 설명**

**적용 속성**

```
freq = 6; decay = 5; amp = 25;
```

### #17. Inertia — 관성(범용)

**한 줄 설명**
어떤 속성이든 키프레임 마지막 지점에서 관성으로 여운이 남는 범용 버전.

**적용 속성**
키프레임이 있는 아무 속성 (최소 2개 키프레임)

```
freq = 3; decay = 5; amp = 0.06;

if (numKeys > 0) {

}
if (n > 0) {
  t = time - key(n).time;
  v = velocityAtTime(key(n).time - 0.01);
  if (t < 2) {
    value + v * amp * Math.sin(freq * t * 2 * Math.PI) * Math.exp(-decay * t);
  } else {
    value;
  }
} else {
  value;
}
```

**조절 가능한 값**

**초보 TIP**

```
freq = 8; decay = 5; amp = 12;
```

#06 Decay Shake과 유사 구조 — 회전 여운 전용으로 활용.

**활용 예시**
🔔 종/스프링 여운 · 📐 회전 정지 후 떨림 · 🎯 정지 순간의 여운감

**주의사항**
#06과 코드가 거의 동일합니다. 차이는 사용 맥락(#06은 충격, #18은 정지 후 여운)뿐이니 헷갈려도 괜찮습니다.

**초보 TIP**
decay를 매우 낮게(2 이하) 하면 거의 멈추지 않고 계속 흔들리므로, "여운"을 표현하려면 decay를 5 이상으로 유지하세요.

**함께 쓰면 좋은 레시피**

<a id="r19"></a>
### #19. Layer Follow — 레이어 따라가기

**한 줄 설명**
다른 레이어의 위치값을 실시간으로 그대로 따라감.

**적용 속성**
Layer → Transform → Position

**Expression**
```
thisComp.layer("타겟").transform.position;
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| "타겟" | 따라갈 레이어 이름 | 실제 레이어명과 정확히 일치 |

**결과**
지정한 레이어와 완전히 동일하게 이동.

**활용 예시**
🔗 오브젝트끼리 붙여서 이동 · 🏷️ 라벨이 제품을 따라다니는 연출

**주의사항**
레이어 이름을 하나라도 다르게 쓰면(띄어쓰기, 대소문자 포함) "레이어를 찾을 수 없다"는 에러가 납니다. 레이어명을 복사해서 붙여넣는 걸 권장합니다.

**초보 TIP**
Parent-Child 관계로도 같은 효과를 낼 수 있지만, 이미 다른 부모가 지정된 레이어라면 이 방식이 더 편합니다.

<a id="r20"></a>
### #20. Delay Follow — 딜레이 따라오기

**한 줄 설명**
바로 따라가지 않고 살짝 늦게 뒤따라옴.

**적용 속성**
Layer → Transform → Position

**Expression**
```
delay = 0.15;
thisComp.layer("타겟").transform.position.valueAtTime(time - delay);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| delay | 지연 시간(초) | 0.05 ~ 0.3 |

**결과**
타겟보다 delay초만큼 늦게 따라오는 부드러운 추적.

**활용 예시**
🎽 캐릭터 뒤에 늦게 따라오는 소품 · 🧵 부드러운 팔로우 연출

**주의사항**
delay가 너무 크면(0.5초 이상) "따라간다"기보다 "따로 논다"는 느낌이 나니 0.3초 이내를 권장합니다.

**초보 TIP**
여러 레이어에 delay 값만 다르게 주면 자연스럽게 #21 Trail(꼬리 효과)이 됩니다.

**함께 쓰면 좋은 레시피**
#21 Trail

<a id="r21"></a>
### #21. Trail — 꼬리 효과

**한 줄 설명**
여러 레이어가 하나씩 시간차를 두고 따라오며 꼬리처럼 이어짐.

**적용 속성**
Layer → Transform → Position (레이어마다 delay 값만 다르게 자동 계산됨)

**Expression**
```
delayPerLayer = 0.05;
delay = (index - 1) * delayPerLayer;
thisComp.layer("타겟").transform.position.valueAtTime(time - delay);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| delayPerLayer | 레이어 하나당 밀리는 시간 | 0.02 ~ 0.1 |

**결과**
index(레이어 순번)가 클수록 더 늦게 따라와 자연스러운 꼬리 형성.

**활용 예시**
🐍 파티클 트레일 · ✨ 잔상 효과 · 🎏 여러 오브젝트가 줄지어 따라가는 연출

**주의사항**
같은 코드를 트레일용 레이어 전부에 그대로 복붙하면 됩니다 — `index`가 레이어마다 자동으로 다르기 때문에 코드를 따로 수정할 필요가 없습니다.

**초보 TIP**
트레일용 레이어들을 위에서부터 순서대로 쌓아 배치하면 index가 자연스럽게 순서를 만듭니다.

**함께 쓰면 좋은 레시피**
#20 Delay Follow, #24 Chain Motion

<a id="r22"></a>
### #22. Auto Chain — 자동 연결

**한 줄 설명**
바로 위 레이어를 자동으로 참조해서 체인처럼 연결됨.

**적용 속성**
Layer → Transform → Position

**Expression**
```
delay = 0.05;
index > 1 ? thisComp.layer(index - 1).transform.position.valueAtTime(time - delay) : value;
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| delay | 레이어 간 지연 시간(초) | 0.03 ~ 0.1 |

**결과**
맨 위 레이어를 제외하고 각 레이어가 바로 위 레이어를 딜레이로 따라감.

**활용 예시**
🔗 체인/목걸이 · 🐛 마디로 이어진 오브젝트 · 🦴 간단한 리깅 대체

**주의사항**
레이어 순서(스택 위치)가 곧 체인 순서이므로, 타임라인에서 레이어 순서를 바꾸면 체인 연결도 바뀝니다.

**초보 TIP**
레이어를 새로 추가/삭제하면 index가 밀리니, 체인 구성이 끝난 뒤에는 레이어 순서를 고정해두는 게 안전합니다.

**함께 쓰면 좋은 레시피**

### #23. Null Tracking — Null 추적

**한 줄 설명**
컨트롤용 널 오브젝트 하나로 여러 레이어를 동시에 조종.

**적용 속성**
Layer → Transform → Position

**Expression**
```
thisComp.layer("Null 1").transform.position;
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| "Null 1" | 참조할 널 레이어 이름 | 실제 널 이름과 일치 |

**결과**
"Null 1"이라는 이름의 널 레이어를 움직이면 이 레이어도 함께 이동.

**활용 예시**
🎛️ 마스터 컨트롤러 구성 · 🖇️ 여러 레이어 한번에 움직이기

**주의사항**
널 레이어 이름이 바뀌면(예: "Null 2"로 변경) 이 익스프레션도 같이 수정해야 합니다.

**초보 TIP**
Parent를 Null로 지정하는 방식이 더 안정적이지만, 부모-자식 관계를 쓰기 어려운 상황(이미 다른 부모가 있을 때)엔 이 방식이 유용합니다.

**함께 쓰면 좋은 레시피**

### #24. Chain Motion — 연쇄 반응

**한 줄 설명**
Null을 움직이면 그 반응이 순서대로 다음 레이어로 전달됨.

**적용 속성**
Layer → Transform → Position

**Expression**
```
delay = 0.08;
d = (index - 1) * delay;
thisComp.layer("Null 1").transform.position.valueAtTime(time - d);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| delay | 한 레이어당 전달 지연 | 0.03 ~ 0.15 |

**결과**
Null을 움직이면 아래 레이어일수록 늦게, 파도처럼 반응.

**활용 예시**
🐛 애벌레처럼 이어지는 움직임 · 🌊 파도처럼 전달되는 연출

**주의사항**
#21 Trail과 코드가 비슷하지만, 참조 대상이 특정 레이어("타겟")가 아니라 고정된 컨트롤 널이라는 점이 다릅니다.

**초보 TIP**
Null 하나만 애니메이션시키면 나머지 레이어 전체가 자동으로 파도처럼 반응하므로, 키프레임 작업량이 크게 줄어듭니다.

### #25. Random Position — 랜덤 위치

**한 줄 설명**
일정한 간격마다 무작위 위치로 순간이동.

**적용 속성**
Layer → Transform → Position

**Expression**
```
freq = 4; amp = 30;
seedRandom(Math.floor(time * freq), true);
value + [random(-amp, amp), random(-amp, amp)];
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 위치가 바뀌는 빈도(초당 횟수) | 2 ~ 10 |
| amp | 이동 거리(px) | 10 ~ 50 |

**결과**
뚝뚝 끊기듯 무작위 위치로 점프(부드러운 흔들림은 #02 Wiggle 사용).

**활용 예시**
✨ 파티클/글리치 연출 · 📺 화면 노이즈 효과

**주의사항**
`seedRandom(...)`을 빼면 매 프레임 다른 값이 나와서 지지직거리는 노이즈가 되어버립니다. 일정 간격으로 뚝뚝 끊기게 하려면 반드시 `seedRandom`과 `Math.floor(time*freq)` 조합을 유지하세요.

**초보 TIP**
Wiggle과 헷갈리기 쉬운데, Wiggle은 부드럽게 흔들리고 이 레시피는 순간이동하듯 뚝뚝 끊깁니다.

**함께 쓰면 좋은 레시피**
#02 Wiggle(부드러운 버전), #28 Random Opacity

### #26. Random Rotation — 랜덤 회전

**한 줄 설명**
일정 간격마다 무작위 각도로 튐 없이 전환.

**적용 속성**
Layer → Transform → Rotation

**Expression**

```
freq = 3; amp = 25;
seedRandom(Math.floor(time * freq), true);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 회전값이 바뀌는 빈도 | 2 ~ 8 |
| amp | 최대 회전 각도 | 10 ~ 40 |

**결과**
일정 간격으로 툭툭 각도가 바뀌는 랜덤 회전.

**활용 예시**
🃏 카드가 흩날리는 연출 · 🌀 글리치 텍스트/이미지

**주의사항**

**초보 TIP**

### #27. Random Scale — 랜덤 Scale

**한 줄 설명**
일정 간격마다 무작위 크기로 바뀜.

**적용 속성**
Layer → Transform → Scale

**Expression**
```
freq = 3; amp = 20;
seedRandom(Math.floor(time * freq), true);

```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 크기가 바뀌는 빈도 | 2 ~ 6 |

### #29. Seed Random — 레이어별 다른 랜덤

**한 줄 설명**
같은 익스프레션을 여러 레이어에 붙여도 레이어마다 다르게 움직이게 만듦.

**적용 속성**
Layer → Transform → Position (여러 레이어에 동일하게 붙여넣기)

**Expression**
```
freq = 2; amp = 20;
seedRandom(index, true);
wiggle(freq, amp);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq / amp | Wiggle과 동일 | freq 1~4, amp 10~30 |

**결과**
index(레이어 번호)가 시드가 되어 레이어마다 서로 다른 패턴으로 흔들림.

**활용 예시**
🎊 여러 파티클/오브젝트를 한 번에 다르게 흔들 때 · 🍃 나뭇잎 여러 장

**주의사항**
이 코드는 "복사해서 여러 레이어에 그대로 붙여넣는 것"이 핵심입니다. 레이어마다 값을 다르게 손봐야 하는 게 아니라, 코드는 완전히 동일하게 두는 게 맞습니다.

**초보 TIP**
효과가 잘 안 보이면 레이어 순서가 겹쳐서 index가 같은 게 아닌지 확인하세요(같은 레이어를 복제만 하고 index가 그대로면 값이 똑같습니다 — 반드시 실제 레이어 스택에 넣어야 합니다).

**함께 쓰면 좋은 레시피**
#02 Wiggle, #27 Random Scale

### #30. Random Delay — 랜덤 딜레이

**한 줄 설명**
같은 애니메이션도 레이어마다 시작 타이밍이 살짝씩 다르게 어긋남.

**적용 속성**
Layer → Transform → Position 등(등장 애니메이션이 있는 속성)

**Expression**
```
maxDelay = 0.3;
seedRandom(index, true);
d = random(0, maxDelay);
value.valueAtTime(time - d);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| maxDelay | 최대로 밀릴 수 있는 시간(초) | 0.1 ~ 0.5 |

**결과**
레이어마다 0~maxDelay초 사이의 랜덤한 딜레이로 시작.

**활용 예시**
🎊 여러 오브젝트가 동시에 등장하면 어색할 때 · ✨ 파티클 등장 타이밍 분산

**주의사항**
이 코드는 "이미 키프레임으로 만든 애니메이션"이 있어야 지연시킬 대상이 있습니다. 애니메이션 자체가 없으면 지연시킬 게 없어 아무 효과도 없습니다.

**초보 TIP**
여러 개의 동일한 등장 애니메이션이 한꺼번에 재생돼서 부자연스러울 때, 이 코드 한 줄만 추가하면 자연스럽게 흩어집니다.

**함께 쓰면 좋은 레시피**

<a id="r31"></a>
### #31. Ease Speed Ramp — 자동 속도조절

**한 줄 설명**
구간에 따라 속도가 저절로 빨라졌다 느려지게 만듦.

**적용 속성**
Layer → Transform → Position(또는 속도 조절이 필요한 아무 속성)

**Expression**
```
t1 = 0; t2 = 2; startVal = 0; endVal = 500;
ease(time, t1, t2, startVal, endVal);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| t1 / t2 | 시작·끝 시간(초) | 원하는 구간으로 |
| startVal / endVal | 시작·끝 값 | 원하는 이동 범위 |

**결과**
키프레임 이징을 직접 만지지 않고도 부드러운 가감속 이동 구현.

**활용 예시**
🎢 가속/감속이 있는 자연스러운 이동 · 📷 카메라 무빙 속도 조절

**주의사항**
이 코드는 키프레임을 대신하는 것이라, 같은 속성에 키프레임이 이미 있으면 그 값을 무시하고 이 계산값으로 덮어씁니다.

**초보 TIP**
`ease`를 `linear`로 바꾸면 가감속 없이 일정한 속도로 이동합니다. 부드러움이 필요 없을 때 참고하세요.

<a id="r33"></a>
### #33. Partial Slow-mo — 슬로우모션(부분 구간)

**한 줄 설명**
특정 구간만 느리게, 나머지는 정상 속도로 재생.

**적용 속성**
Layer → Time → Time Remap

**Expression**
```
slowStart = 1; slowEnd = 2; slowFactor = 0.3;
if (time < slowStart) {
  time;
} else if (time < slowEnd) {
  slowStart + (time - slowStart) * slowFactor;
} else {
  slowStart + (slowEnd - slowStart) * slowFactor + (time - slowEnd);
}
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| slowStart / slowEnd | 느려질 구간(초) | 강조하고 싶은 구간 |
| slowFactor | 느려지는 배율(0.3=30% 속도) | 0.1 ~ 0.5 |

**결과**
지정 구간만 슬로우, 앞뒤는 정상 속도.

**활용 예시**
🐢 임팩트 순간만 강조하고 싶을 때 · 🏃 액션 하이라이트 구간

**주의사항**
#32와 마찬가지로 Time Remap이 켜져 있어야 합니다. slowEnd 이후 구간이 원본보다 짧아 보일 수 있으니 레이어 길이를 여유 있게 잡으세요.

**초보 TIP**
slowFactor를 0에 가깝게 하면 거의 정지(프리즈 프레임)처럼 보입니다.

**함께 쓰면 좋은 레시피**

### #38. Counter — 카운터(목표값+콤마 포맷)

**한 줄 설명**

**적용 속성**
Layer → Text → Source Text


|---|---|---|

**초보 TIP**

### #40. Timecode — 시간 표시(mm:ss)

**한 줄 설명**

| "오디오 레이어명" | 오디오 이펙트가 적용된 레이어 이름 | 실제 레이어명과 일치 |

**결과**
소리 크기에 비례해 실시간으로 커졌다 작아짐.

**활용 예시**
🎵 음악 시각화 · 🔊 스피커 아이콘 반응

**주의사항**
오디오 레이어에 Audio Amplitude 이펙트가 없으면 "effect를 찾을 수 없다"는 에러가 납니다. 이펙트 이름과 채널명("Left Channel")도 정확히 일치해야 합니다.

**초보 TIP**
반응이 너무 과하면 sensitivity를 낮추고, 반응이 잘 안 느껴지면 오디오 레이어의 Audio Amplitude 이펙트 안에 있는 자체 게인(Gain) 값을 올려보세요.

**함께 쓰면 좋은 레시피**

### #45. Audio Wiggle — 음악에 맞춰 Wiggle

**한 줄 설명**
비트가 강할수록 흔들림이 커짐.

**적용 속성**
Layer → Transform → Position

**Expression**
```
freq = 4; sensitivity = 0.5;
audioLayer = thisComp.layer("오디오 레이어명");
amp = audioLayer.effect("Audio Amplitude")("Left Channel");
wiggle(freq, amp * sensitivity);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 흔들리는 속도 | 2 ~ 6 |
| sensitivity | 오디오 반응 정도 | 0.3 ~ 1 |

**결과**
조용할 땐 거의 안 움직이다가 소리가 커지면 흔들림도 커짐.

**활용 예시**

**주의사항**
`wiggle()`의 두 번째 인자(amp)가 음수가 되면 에러가 날 수 있으니, `amp * sensitivity`가 항상 0 이상인지 확인하세요(오디오 앰플리튜드 값은 보통 0 이상입니다).

**초보 TIP**
너무 정신없이 흔들리면 freq를 낮추고 sensitivity를 낮추는 순서로 조절해보세요.

### #47. Beat Pulse — 비트 펄스

**한 줄 설명**
소리가 일정 크기(threshold)를 넘을 때만 통통 튐.

**적용 속성**
Layer → Transform → Scale

**Expression**
```
threshold = 20; punch = 15;
audioLayer = thisComp.layer("오디오 레이어명");

```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| threshold | 반응을 시작할 소리 크기 기준 | 오디오에 맞춰 조절 |
| punch | 튀는 정도(%) | 5 ~ 20 |

**결과**
기준치를 넘는 비트에서만 순간적으로 커짐.

**활용 예시**
🥁 킥드럼에 맞춰 통통 튀는 로고 · 🕺 비트 강조 연출

**주의사항**

**초보 TIP**

### #49. Clamp — 값 제한

**한 줄 설명**
값이 특정 범위를 절대 벗어나지 않도록 제한.

**적용 속성**
제한이 필요한 아무 속성

**Expression**
```
minVal = 0; maxVal = 100;
clamp(value, minVal, maxVal);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| minVal / maxVal | 허용 최소/최대값 | 상황에 맞게 |

**결과**
값이 아무리 커지거나 작아져도 지정 범위 안에서만 움직임.

**활용 예시**
🚧 드래그 범위 제한 · 📊 프로그레스바가 100% 넘지 않게

**주의사항**
`clamp()`는 단독으로는 아무 움직임도 만들지 않는 "제한 함수"입니다. 다른 익스프레션과 함께 조합해서 써야 의미가 있습니다(예: `clamp(wiggle(2,50)[0], -100, 100)`처럼).

**초보 TIP**
프로그레스바 값이 100%를 넘어가는 실수를 방지할 때 가장 많이 씁니다.

**함께 쓰면 좋은 레시피**

### #50. Slider Control — 슬라이더 컨트롤

**한 줄 설명**

② 원하는 속성(예: Position)에 아래 코드 적용


**초보 TIP**

Layer → Transform → Position, Rotation 둘 다 적용

**Expression**
```
[Position] freq = 4; amp = 6; wiggle(freq, amp);
[Rotation] freq = 4; amp = 0.8; wiggle(freq, amp);
```

**조절 가능한 값**
| 값 | 의미 | 추천 |
|---|---|---|
| freq | 두 속성 동일하게 맞출 것 | 3 ~ 6 |
| amp | Position 3~10px / Rotation 0.3~1.5도 | - |

**결과**
위치+회전이 같은 리듬으로 흔들려 리얼한 손떨림 구현.

**활용 예시**
📱 폰카 촬영 느낌 재현 · 📸 제품컷에 생동감 추가

**주의사항**
Position과 Rotation의 freq를 다르게 하면 두 움직임이 서로 어긋나 보여 부자연스럽습니다. 반드시 같은 값으로 맞추세요.

**초보 TIP**
이 코드는 Position과 Rotation, 두 속성에 각각 따로 붙여야 합니다. 하나의 코드로 두 속성을 동시에 제어할 수 없습니다.

`finalX = value[0]`은 현재 Position의 X값을 "최종 도착 지점"으로 자동 인식하는 구조입니다. 이 레이어의 Position 자체는 건드리지 말고 최종 위치에 그대로 둔 채 이 코드만 붙이세요.

**초보 TIP**
왼쪽에서 들어오게 하려면 fromOffset을 음수(-300)로 바꾸세요.

**함께 쓰면 좋은 레시피**
#16 Overshoot(더 탄력있는 슬라이드를 원하면 응용), #38 Counter(카드 안 숫자에 활용)

### #69. Button Press — UI 인터랙션(버튼 눌림 피드백)

**한 줄 설명**
버튼을 누른 것처럼 살짝 작아졌다가 원래대로 돌아옴.

**적용 속성**
① Effect → Expression Controls → Checkbox Control 추가(클릭 트리거용)
② Scale에 아래 코드 적용

**Expression**
```
pressed = effect("Checkbox Control")("Checkbox");
s = pressed == 1 ? 92 : 100;
[s, s];
```

**조절 가능한 값**
없음(체크박스로 On/Off)

**결과**
체크박스를 체크하는 타이밍에 버튼이 살짝 눌리는 느낌으로 축소.

**활용 예시**
🖱️ 클릭 피드백 · 📱 앱 인터랙션 목업

**주의사항**
체크박스를 계속 체크된 상태로 두면 버튼이 계속 작아진 채로 고정됩니다. 반드시 짧게 체크했다 해제하는 키프레임을 넣어야 "눌림→복귀"가 표현됩니다.

**초보 TIP**
체크박스 키프레임을 3~5프레임 정도로 아주 짧게 넣으면 실제 클릭처럼 순간적인 눌림 효과가 됩니다.

**함께 쓰면 좋은 레시피**
#62 Button Hover

### #70. 치트시트 — 자주 쓰는 익스프레션 모음

**한 줄 설명**
매번 챕터를 찾아보기 번거로운 한 줄짜리 표현들만 모은 요약표.

**적용 속성**
표 참고

| 목적 | 코드 | 관련 레시피 |
|---|---|---|
| 기본 흔들림 | `wiggle(2, 20)` | #02 |
| 무한 반복 | `loopOut("cycle")` | #07 |
| 왕복 반복 | `loopOut("pingpong")` | #08 |
| 무한 회전 | `time * 90` | #10 |
| 값 제한 | `clamp(value, 0, 100)` | #49 |
| 지연 참조 | `value.valueAtTime(time - 0.2)` | #54 |
| 다른 레이어 참조 | `thisComp.layer("이름").transform.position` | #19 |
| 레이어별 다른 랜덤 | `seedRandom(index, true); wiggle(2, 20)` | #29 |
| 부드러운 보간 | `ease(time, 0, 1, 0, 100)` | #31 |
| 숫자 카운터 | `Math.round(ease(time,0,2,0,1000)).toLocaleString()` | #38 |

**결과**
빠르게 코드만 복사해서 쓰고 싶을 때 이 표만 훑으면 됩니다.

**활용 예시**
전체 챕터 공통

**주의사항**
표의 코드는 최소 버전이라, 실제로는 각 레시피 페이지의 전체 코드(변수 선언 포함)를 쓰는 걸 권장합니다.

**초보 TIP**
급할 땐 이 표에서 코드를 먼저 붙이고, 나중에 여유 있을 때 원본 레시피 페이지로 가서 조절값 설명을 읽어보세요.

**함께 쓰면 좋은 레시피**
전체 레시피

### #71. 조합 프리셋 — 자주 쓰는 조합 레시피

**한 줄 설명**
단일 익스프레션보다 실무에서는 조합해서 쓰는 경우가 많아서 대표 조합만 정리.

**적용 속성**
아래 조합 참고

**Expression**
아래 각 조합에 표시된 레시피 번호의 코드를 그대로 사용

**조절 가능한 값**
각 레시피 페이지의 조절값 참고

**결과**
"등장 → 유지 → 반응"의 흐름으로 조합하면 실무 완성도가 확 올라감.

**활용 예시**
- **제품컷 부유감**: Position에 #01 Float + Rotation에 #03 Swing(amp를 2~4로 작게)
- **인트로 로고**: #67 Logo Reveal + 배경 레이어에 #57 Auto Parallax
- **브이로그 손맛**: #56 Handheld Feel 전체 레이어 적용 + 컷 전환 시 #06 Decay Shake
- **SNS 카드뉴스**: #68 Card Slide-in + 텍스트에 #38 Counter 또는 #37 Number Increase
- **UI 목업 시연**: #62 Button Hover + #69 Button Press(체크박스 두 개로 나눠서 각각 연결)

**주의사항**
조합할 때 같은 속성(예: Position)에 두 코드를 동시에 넣을 수는 없습니다 — 서로 다른 속성(Position/Rotation/Scale/Opacity)에 나눠서 적용해야 합니다.

**초보 TIP**
처음엔 레시피 하나씩만 적용해서 각각의 느낌을 확인한 뒤, 조합은 그다음 단계로 시도해보세요.

**함께 쓰면 좋은 레시피**
